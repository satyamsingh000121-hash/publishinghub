# The Publishing — Dark Theme CSS

This folder contains the complete CSS theme for the dark bookstore homepage design.

## Main file
- `publishing-theme.css`

## Design system
- Background: near-black
- Primary accent: deep forest green
- Secondary accent: muted antique gold
- Text: warm ivory
- Display font: Cormorant Garamond
- UI font: Inter

The CSS is responsive for desktop, tablet, and mobile.

Important:
The CSS controls layout, typography, colors, spacing, cards, buttons, grids, footer, responsiveness, and visual effects. The exact book/author/background images are separate assets and are intentionally not included.
